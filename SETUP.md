# Before you arrive

**15 minutes.** Please don't skip it. Everyone who does spends the first half
hour of the workshop catching up instead of building.

**You do not need to pay for anything and you do not need to know how to code.**

---

## 1. A Claude account (5 min)

Sign up free at [claude.ai](https://claude.ai), or install
[Claude Desktop](https://claude.ai/download) and sign in.

- [ ] I can open a chat and get a reply

**Free is genuinely enough.** You need to upload a file and have Claude run code
on it, and both work on the free plan. See [`TIPS.md`](TIPS.md) if you want the
full plan comparison.

## 2. A GitHub account (3 min)

Sign up free at [github.com/signup](https://github.com/signup).

- [ ] I'm signed in to github.com

## 3. Make your own copy of this repo (5 min)

**Don't fork it, use the template button.** You get your own independent repo
that you control.

1. Scroll to the top of this repo and click the green **Use this template** button
2. Choose **Create a new repository**
3. Name it `my-budget-app`. Leave it Public. Click **Create repository**
4. In your new repo, go to **Settings** (top bar) → **Pages** (left sidebar)
5. Under "Build and deployment", set **Source** to `Deploy from a branch`,
   branch `main`, folder `/ (root)`. Click **Save**
6. Wait about two minutes, then open
   `https://YOUR-USERNAME.github.io/my-budget-app/template/`

- [ ] I can see a page that says **"Hello, Budget"**

**If you see that, you're done.** That page is the starter template you'll build
on. Getting this working at home is the single thing that makes the workshop run
on time.

<details>
<summary>It says 404, or nothing loads</summary>

- Pages takes a couple of minutes on first publish. Refresh after 2 minutes.
- Check the URL ends with `/template/`, including the trailing slash.
- Check **Settings → Pages** says "Your site is live at ...". If it doesn't,
  the branch or folder setting didn't save.
- Still stuck? Bring it on the day, we'll fix it in the first ten minutes.
</details>
